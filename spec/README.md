# spec

The wire format, evidence pack format, and conformance vectors. Empty until M6.

This directory is deliberately separable. The "be the format" position depends on other
people — including competitors and hyperscalers — being able to implement a witness against
these documents without vendoring anything from a product repository. Expect this to be
extracted into its own public repository once a second implementer appears.

Governed by `FR-46` (open conformance suite), `GOV-06` and `GOV-07` (the certification mark
is granted on a passing run, and on nothing else).
